# NordVPN 官方授权专线站 (nordvpn.help) — 项目概述

本项目为 **NordVPN 官方授权全球专线网络（nordvpn.help）** 建设的高标准独立品牌落地页与转化系统。

## 核心定位与原则

1. **品牌官方授权服务站**：展现正品、可信、现代、安全的品牌专线服务形象。
2. **严禁评测站/导航站属性**：绝不建设第三方评测、机场导航或多品牌比价内容。
3. **真实透明**：全节点采用 IEPL/IPLC 物理专线与 VLESS 现代协议，全节点 ×1 真实倍率，绝不暗扣或虚标。
4. **统一转化链接**：`https://sahude.gsyvipaff.com/#/?code=keqgvT5Y`（必须携带 `rel="nofollow noopener noreferrer"`）。

## 架构规划

- 核心落地页：首页 (`/`)
- 套餐对比：`/pricing`
- 专线技术：`/features`
- 节点遥测：`/status`
- 品牌支持：`/about`, `/contact`
- 合规协议：`/privacy`, `/terms`
- 注册与登录转化：`/sign-up`, `/sign-in`
