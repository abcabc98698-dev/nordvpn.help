# NordVPN 官方授权专线站 (nordvpn.help) — 产品需求规格书 (PRD)

## 1. 项目背景与目标

NordVPN 官方授权专线网络（nordvpn.help）自 2020 年起稳定运营，致力于为高频 AI 创作者、跨境出海电商团队及追求高品质流媒体互联的用户提供企业级 IEPL 物理专线与新一代 VLESS 现代协议。

## 2. 目标与验收标准

- **形象目标**：建立权威、高端、可信的品牌官方服务站形象。
- **转化目标**：通过清晰透明的 4 大真实套餐（147永久套餐、年付轻量版、极速版、企业定制版）与多端自研客户端支持，实现极速开通转化。
- **SEO 权重保护**：全站所有指向外部授权开通系统的按钮与链接统一强制携带 `rel="nofollow noopener noreferrer"`。

## 3. 技术标准

- Framework: Astro 6 + Content Layer
- Styling: Tailwind CSS v4 (@theme)
- Protocol: VLESS
- Backbone: IEPL / IPLC 物理专线直连
- Coverage: 香港×20、台湾×5、日本×10、新加坡×10、美国×10、马来西亚×2、欧洲英法德、土耳其/巴西等
- Uptime SLA: 99.98%
